Detailed Description

template<typename Filter>
class fcarouge::sample::internal::benchmarker< Filter >

Filter decorator benchmarking the first prediction and update.

Repeats the call on a filter copy, then prints the method, median nanoseconds, error percentage, and instructions, or - without counters.
