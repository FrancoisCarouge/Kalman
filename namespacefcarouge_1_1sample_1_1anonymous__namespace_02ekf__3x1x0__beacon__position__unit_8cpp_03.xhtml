const auto fcarouge::sample::anonymous_namespace{ekf_3x1x0_beacon_position_unit.cpp}::beacon_range_jacobian
Initial value:
{[](const position &point,
const position &beacon) -> range_jacobian {
const position displacement{point - beacon};
const length distance{displacement.magnitude()};
const auto [north_component, east_component, down_component]{displacement};
range_jacobian value;
value.at<0>((north_component / distance).numerical_value_in(mp_units::one) *
(mp_units::isq::length / north)[mp_units::one]);
value.at<1>((east_component / distance).numerical_value_in(mp_units::one) *
(mp_units::isq::length / east)[mp_units::one]);
value.at<2>((down_component / distance).numerical_value_in(mp_units::one) *
(mp_units::isq::length / down)[mp_units::one]);
return value;
}}

fcarouge::sample::anonymous_namespace{ekf_3x1x0_beacon_position_unit.cpp}::down down

The derivative of the range with respect to the point: the components of the unit vector from the beacon to the point.

A component of the unit vector, an axis displacement by the range, is the quantity north/length for the north axis, while the derivative of the range by that axis is the reciprocal quantity, length/north: their values are equal, their quantities distinct. The value of the component is therefore restated as the derivative.
