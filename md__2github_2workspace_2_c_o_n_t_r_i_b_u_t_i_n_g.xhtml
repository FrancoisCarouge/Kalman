Pre-commit Hooks

This repository uses pre-commit to catch formatting and linting issues before they reach a commit. The same hooks run in CI on every pull request, via the Pre-commit workflow, but installing them locally catches issues before you push. Secret scanning is enforced separately: the gitleaks pre-commit hook only checks staged changes at commit time, so the Gitleaks workflow additionally runs gitleaks/gitleaks-action to scan the full push or pull request diff in CI.

pip install pre-commit
pipx install cmakefmt
pre-commit install

Once installed, the hooks run automatically on git commit. To run them against the whole repository at any time:

pre-commit run --all-files

See .pre-commit-config.yaml for the exact hook set and versions (cmakefmt for CMake formatting, always the latest release from your $PATH, so keep it current with pipx upgrade cmakefmt, clang-format v22 for C++ formatting, gitleaks for secrets, codespell for spelling, actionlint and check-jsonschema for workflow, Dependabot, and citation validation, local SPDX header, zero NOLINT, and [tag] description commit message checks, plus line ending, whitespace, and end-of-file fixers).
