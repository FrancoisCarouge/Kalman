Attitude of a camera gimbal and bias of its gyroscope, an error-state extended filter.

Attitude of a camera gimbal and bias of its gyroscope, an error-state extended filter.

Copyright
This example is inspired by the gimbal attitude filter of the ArduPilot autopilot (SmallEKF), by the ArduPilot Dev Team. The model is written from its equations, not transcribed from its code.
See also
https://ardupilot.org/copter/docs/common-mounts.html
https://github.com/ArduPilot/ardupilot/blob/Copter-3.3/libraries/AP_NavEKF/AP_SmallEKF.cpp
Joan Solà, Quaternion Kinematics for the Error-State Kalman Filter, 2017, https://arxiv.org/abs/1711.02508

A camera gimbal on a vehicle at rest pans slowly about the down axis while its tilt oscillates. The inertial sensors of the camera measure its rotation and specific force: the gyroscope, offset by an unknown bias, and the accelerometer, fifty times a second. Ten times a second, a compass measures the heading:

The gimbal integrates the gyroscope and accelerometer increments into a nominal attitude and velocity. The filter does not estimate them directly: its nine states are the errors of the nominal values, the attitude error as a rotation vector in the north, east, and down frame, the velocity error, and the gyroscope bias in the body frame. Each axis is a quantity kind of its own. The state transition F is computed from the prediction arguments, the attitude and the velocity increment. The output model H is constant: the vehicle at rest observes a zero velocity, and the heading error of a nearly level camera is the down attitude error. Each correction moves the estimated errors into the nominal values and resets them to zero.

The tilt converges within seconds: a tilt error turns gravity into a velocity error, which the zero velocity observes. The heading and the yaw rate bias converge more slowly, as the compass averages out its noise, to a heading error well within the compass noise.

The autopilot's filter differs: its nominal attitude is a quaternion, it fuses the vehicle velocity of the main navigation filter, and it aligns its initial heading once the tilt has converged.

using mp_units::quantity;
using mp_units::si::unit_symbols::m;
using mp_units::si::unit_symbols::m2;
using mp_units::si::unit_symbols::rad;
using mp_units::si::unit_symbols::s;
using mp_units::si::unit_symbols::s2;
constexpr auto rad2{pow<2>(rad)};
using heading = quantity<down_angle[rad]>;
using ned_rotation_vector = quantity<ned_rotation[rad], Eigen::Vector3d>;
using ned_velocity_vector = quantity<ned_velocity[m / s], Eigen::Vector3d>;
using ned_acceleration_vector =
quantity<ned_acceleration[m / s2], Eigen::Vector3d>;
using body_rotation_vector = quantity<body_rotation[rad], Eigen::Vector3d>;
using body_angular_velocity_vector =
quantity<body_angular_velocity[rad / s], Eigen::Vector3d>;
using body_velocity_vector = quantity<body_velocity[m / s], Eigen::Vector3d>;
using attitude = Eigen::Matrix3d;
template <typename... Types> using vector = column_vector<double, Types...>;
using error_state =
vector<quantity<north_angle[rad]>, quantity<east_angle[rad]>,
quantity<down_angle[rad]>, quantity<north_velocity[m / s]>,
quantity<east_velocity[m / s]>, quantity<down_velocity[m / s]>,
quantity<roll_rate[rad / s]>, quantity<pitch_rate[rad / s]>,
quantity<yaw_rate[rad / s]>>;
using error_measurement =
vector<quantity<north_velocity[m / s]>, quantity<east_velocity[m / s]>,
quantity<down_velocity[m / s]>, heading>;
using error_state_indexes = error_state::row_indexes;
using error_measurement_indexes = error_measurement::row_indexes;
using reciprocal_error_state =
std::tuple<quantity<mp_units::one / north_angle[rad]>,
quantity<mp_units::one / east_angle[rad]>,
quantity<mp_units::one / down_angle[rad]>,
quantity<mp_units::one / north_velocity[m / s]>,
quantity<mp_units::one / east_velocity[m / s]>,
quantity<mp_units::one / down_velocity[m / s]>,
quantity<mp_units::one / roll_rate[rad / s]>,
quantity<mp_units::one / pitch_rate[rad / s]>,
quantity<mp_units::one / yaw_rate[rad / s]>>;
using transition_jacobian =
matrix<double, error_state_indexes, reciprocal_error_state>;
using measurement_jacobian =
matrix<double, error_measurement_indexes, reciprocal_error_state>;
using error_state_covariance =
matrix<double, error_state_indexes, error_state_indexes>;
using error_measurement_covariance =
matrix<double, error_measurement_indexes, error_measurement_indexes>;
constexpr auto time_step{0.02 * s};
const auto rotation{[](const Eigen::Vector3d &angle) -> attitude {
return Eigen::AngleAxisd{angle.norm(), angle.normalized()}.toRotationMatrix();
}};
const auto rotate_body{[](const attitude &body_to_ned,
const body_rotation_vector &angle) -> attitude {
return attitude{body_to_ned * rotation(angle.numerical_value_in(rad))};
}};
const auto rotate_ned{[](const ned_rotation_vector &angle,
const attitude &body_to_ned) -> attitude {
return attitude{rotation(angle.numerical_value_in(rad)) * body_to_ned};
}};
const auto to_ned{
[](const attitude &body_to_ned,
const body_velocity_vector &velocity) -> ned_velocity_vector {
return Eigen::Vector3d{body_to_ned * velocity.numerical_value_in(m / s)} *
ned_velocity[m / s];
}};
const auto to_body{
[](const attitude &body_to_ned,
const ned_velocity_vector &velocity) -> body_velocity_vector {
return Eigen::Vector3d{body_to_ned.transpose() *
velocity.numerical_value_in(m / s)} *
body_velocity[m / s];
}};
const auto heading_of{[](const attitude &body_to_ned) -> heading {
return std::atan2(body_to_ned(1, 0), body_to_ned(0, 0)) * down_angle[rad];
}};
const auto wrap{[](const heading &angle) -> heading {
return remainder(angle, 2. * std::numbers::pi * down_angle[rad]);
}};
const auto state_transition_of{
[](const attitude &body_to_ned,
const body_velocity_vector &delta_velocity) -> transition_jacobian {
transition_jacobian value{transition_jacobian::matrix::Identity()};
[&body_to_ned,
&value]<std::size_t... Index>(std::index_sequence<Index...>) -> void {
(value.at<Index / 3, 6 + (Index % 3)>(
transition_jacobian::element<Index / 3, 6 + (Index % 3)>{
-body_to_ned(static_cast<Eigen::Index>(Index / 3),
static_cast<Eigen::Index>(Index % 3)) *
time_step}),
...);
}(std::make_index_sequence<9>{});
const auto [north, east, down] = to_ned(body_to_ned, delta_velocity);
value.at<3, 1>(down.numerical_value_in(m / s) *
(north_velocity / east_angle)[m / s / rad]);
value.at<3, 2>(-east.numerical_value_in(m / s) *
(north_velocity / down_angle)[m / s / rad]);
value.at<4, 0>(-down.numerical_value_in(m / s) *
(east_velocity / north_angle)[m / s / rad]);
value.at<4, 2>(north.numerical_value_in(m / s) *
(east_velocity / down_angle)[m / s / rad]);
value.at<5, 0>(east.numerical_value_in(m / s) *
(down_velocity / north_angle)[m / s / rad]);
value.at<5, 1>(-north.numerical_value_in(m / s) *
(down_velocity / east_angle)[m / s / rad]);
return value;
}};
[[maybe_unused]] const auto sample{[] -> int {
const ned_acceleration_vector gravity{Eigen::Vector3d{0., 0., 9.80665} *
ned_acceleration[m / s2]};
const body_angular_velocity_vector true_bias{roll_rate(0.01 * rad / s),
pitch_rate(-0.02 * rad / s),
yaw_rate(0.005 * rad / s)};
const auto gyroscope_noise{0.001 * rad / s};
const auto accelerometer_noise{0.05 * m / s2};
// The bias random walk of 1e-4 rad.s^-1 per square root of second, over a
// step.
const auto bias_noise{1e-4 * rad / (s * sqrt(s)) * sqrt(time_step)};
kalman filter{
// The state X: the errors, zero after each correction.
state{error_state{}},
// The output Z: the errors of the velocity and of the heading.
output<error_measurement>,
// The estimate uncertainty P:
estimate_uncertainty{[]() -> error_state_covariance {
error_state_covariance value;
value.at<0, 0>(0.01 * rad2);
value.at<1, 1>(0.01 * rad2);
value.at<2, 2>(0.01 * rad2);
value.at<3, 3>(0.01 * m2 / s2);
value.at<4, 4>(0.01 * m2 / s2);
value.at<5, 5>(0.01 * m2 / s2);
value.at<6, 6>(0.0025 * rad2 / s2);
value.at<7, 7>(0.0025 * rad2 / s2);
value.at<8, 8>(0.0025 * rad2 / s2);
return value;
}()},
// The process uncertainty Q, of the sensor noises over a step:
process_uncertainty{[&]() -> error_state_covariance {
const auto attitude_variance{pow<2>(gyroscope_noise * time_step)};
const auto velocity_variance{pow<2>(accelerometer_noise * time_step)};
error_state_covariance value;
value.at<0, 0>(attitude_variance);
value.at<1, 1>(attitude_variance);
value.at<2, 2>(attitude_variance);
value.at<3, 3>(velocity_variance);
value.at<4, 4>(velocity_variance);
value.at<5, 5>(velocity_variance);
value.at<6, 6>(pow<2>(bias_noise));
value.at<7, 7>(pow<2>(bias_noise));
value.at<8, 8>(pow<2>(bias_noise));
return value;
}()},
// The output uncertainty R:
output_uncertainty{[]() -> error_measurement_covariance {
error_measurement_covariance value;
value.at<0, 0>(0.01 * m2 / s2);
value.at<1, 1>(0.01 * m2 / s2);
value.at<2, 2>(0.01 * m2 / s2);
value.at<3, 3>(0.0025 * rad2);
return value;
}()},
// The output model H selects the observed errors:
output_model{[](const error_state &) -> measurement_jacobian {
measurement_jacobian value;
value.at<0, 3>(1.);
value.at<1, 4>(1.);
value.at<2, 5>(1.);
value.at<3, 2>(1.);
return value;
}},
// The state transition F, of the attitude and the velocity increment:
state_transition{state_transition_of},
// The observation h(X) of the observed errors:
observation{[](const error_state &errors) -> error_measurement {
return error_measurement{errors.at<3>(), errors.at<4>(), errors.at<5>(),
errors.at<2>()};
}},
// The filter prediction uses the attitude and the velocity increment.
prediction_types<attitude, body_velocity_vector>};
// The nominal values the errors correct.
attitude body_to_ned{rotate_ned(ned_rotation_vector{north_angle(0.02 * rad),
east_angle(-0.03 * rad),
down_angle(0.1 * rad)},
attitude::Identity())};
ned_velocity_vector velocity{Eigen::Vector3d{Eigen::Vector3d::Zero()} *
ned_velocity[m / s]};
body_angular_velocity_vector bias{Eigen::Vector3d{Eigen::Vector3d::Zero()} *
body_angular_velocity[rad / s]};
// Move the estimated errors into the nominal values and reset them.
const auto reset{[&filter, &body_to_ned, &velocity, &bias] -> void {
const error_state errors{filter.x()};
body_to_ned = rotate_ned(
ned_rotation_vector{errors.at<0>(), errors.at<1>(), errors.at<2>()},
body_to_ned);
velocity +=
ned_velocity_vector{errors.at<3>(), errors.at<4>(), errors.at<5>()};
bias += body_angular_velocity_vector{errors.at<6>(), errors.at<7>(),
errors.at<8>()};
filter.x(error_state{});
}};
attitude true_body_to_ned{attitude::Identity()};
const int steps{1500};
for (int step{0}; step < steps; ++step) {
const auto time{step * time_step};
// The true motion: a slow pan with a small oscillation in tilt.
const body_angular_velocity_vector true_rate{
roll_rate(0.05 * rad / s * mp_units::si::sin(0.3 * rad / s * time)),
pitch_rate(0.05 * rad / s * mp_units::si::cos(0.2 * rad / s * time)),
yaw_rate(0.1 * rad / s)};
const body_rotation_vector delta_angle{(true_rate + true_bias) * time_step};
const body_velocity_vector delta_velocity{
to_body(true_body_to_ned, -gravity * time_step)};
true_body_to_ned = rotate_body(true_body_to_ned, true_rate * time_step);
// Predict the errors over the step, then integrate the nominal values.
filter.predict(body_to_ned, delta_velocity);
velocity += to_ned(body_to_ned, delta_velocity) + (gravity * time_step);
body_to_ned = rotate_body(body_to_ned, delta_angle - (bias * time_step));
// Ten times a second, observe the zero velocity of the vehicle at rest,
// and the heading of the compass.
if (step % 5 == 0) {
const heading measured{
heading_of(true_body_to_ned) +
(0.05 * std::sin(12.9898 * step) * down_angle[rad])};
const auto [north, east, down]{velocity};
filter.update(-north, -east, -down,
wrap(measured - heading_of(body_to_ned)));
reset();
}
}
assert((bias - true_bias).numerical_value_in(rad / s).norm() < 0.001 &&
"The gyroscope bias is found within a milliradian per second.");
assert(abs(wrap(heading_of(body_to_ned) - heading_of(true_body_to_ned))) <
0.01 * rad &&
"The heading is found within ten milliradians.");
return 0;
}()};
