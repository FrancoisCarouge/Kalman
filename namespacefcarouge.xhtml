template<typename... Arguments>
fcarouge::kalman ( Arguments... arguments) -> kalman< kf::deduce_filter< Arguments... > >

Deduces the filter type from its declared configuration.

The configuration arguments passed are used to determine at compile time the type of filter to use. The objective is to select the most performant filter within the defined configuration parameters. Declare the configuration with a single scalar representation to avoid narrowing in the filter equations: mixed built-in arithmetic types are rejected. A configuration with an observation function may omit the transition function: the state is then predicted by the state transition F, X = F.X, as for a state that does not change between predictions.
