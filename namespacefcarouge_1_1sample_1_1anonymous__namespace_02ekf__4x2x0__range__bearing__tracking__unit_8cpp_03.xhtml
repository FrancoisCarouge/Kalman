Initial value:
{[](const track &estimate) -> measurement_jacobian {
const length along_x{estimate.at<0>()};
const length along_y{estimate.at<1>()};
const squared_length squared{(along_x * along_x) + (along_y * along_y)};
const length hypotenuse{hypot(along_x, along_y)};
measurement_jacobian value;
value.at<0, 0>((bearing / x_position)(-along_y / squared));
value.at<0, 1>((bearing / y_position)(along_x / squared));
value.at<1, 0>((range / x_position)(along_x / hypotenuse));
value.at<1, 1>((range / y_position)(along_y / hypotenuse));
return value;
}}

The output model H = ∂h/∂X of the polar coordinates, at a state.

The bearing derives from the x position by -y/r², from the y position by x/r², the quantities bearing per x or y position. The range derives from them by the components of the unit vector toward the target, x/r and y/r. Neither depends on the velocity. An angle is an arc length by its radius: the ratios of the lengths are restated as the derivatives.
