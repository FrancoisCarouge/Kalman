Position of a receiver from its ranges to beacons at known positions.

Position of a receiver from its ranges to beacons at known positions.

Copyright
This example is inspired by the static position alignment of the range beacon fusion of the ArduPilot autopilot's third generation extended Kalman filter (EKF3), by the ArduPilot Dev Team, itself based on the range beacon derivation of Paul Riseborough's InertialNav project. The model is written from the derivation's equations, not transcribed from either code.
See also
https://ardupilot.org/copter/docs/common-pozyx.html
https://github.com/ArduPilot/ardupilot/blob/master/libraries/AP_NavEKF3/AP_NavEKF3_RngBcnFusion.cpp
https://github.com/priseborough/InertialNav/blob/master/derivations/range_beacon.m
Yaakov Bar-Shalom, X. Rong Li, Thiagalingam Kirubarajan, Estimation with Applications to Tracking and Navigation, John Wiley & Sons, 2001, the normalized innovation squared consistency test, https://doi.org/10.1002/0471221279

A receiver at rest among four radio beacons at known positions, north, east, and down [m], measures its range to one beacon at a time. As in the ArduPilot setup of the Pozyx beacons, the beacons stand at the corners of a rectangle, numbered along an N pattern from the origin beacon, the line from the origin to the second beacon due north:

A position is a vector quantity: the displacement from the origin beacon, decomposed into its north, east, and down axes, each a quantity kind of its own, so that no axis is added to, nor substituted for, another. The state is the receiver's position, by its axis components, constant but for a small process noise. The observation composes the components back into a vector, whose magnitude is the range. The range is nonlinear in the position: the output model H = ∂h/∂X is the unit vector from the beacon to the receiver, evaluated at the estimate. The beacons stand at different heights, so the vertical position is observable, yet less so than the horizontal position: the receiver sees the beacons from nearly level. Early in the alignment, the vertical estimate crosses to the mirror solution below the ground, where the ranges are nearly as consistent, before the geometry of the beacons resolves the ambiguity. Autopilots such as ArduPilot align the position of their navigation filter with such a filter before using the beacons.

Until the alignment is complete, after a hundred ranges, every range is fused. Afterwards a range is fused only if consistent with the estimate: its innovation must lie within three of its standard deviations, a gate on the normalized innovation squared. A multipath reflection, measuring a longer path, is rejected.

The autopilot's filter differs in its tuning: its initial variances are the mean range, its process noise is larger, its range noise is reported by the beacons, and it estimates a vertical offset of the beacons separately.

namespace fcarouge::sample {
namespace {
using mp_units::si::unit_symbols::m;
using mp_units::si::unit_symbols::m2;
using length = mp_units::quantity<mp_units::isq::length[m]>;
using position =
mp_units::quantity<ned_displacement[m],
mp_units::utility::cartesian_vector<double>>;
template <typename... Types> using vector = column_vector<double, Types...>;
using coordinates =
vector<mp_units::quantity<north[m]>, mp_units::quantity<east[m]>,
mp_units::quantity<down[m]>>;
using range = vector<length>;
using range_jacobian =
matrix<double, std::tuple<length>,
std::tuple<mp_units::quantity<mp_units::one / north[m]>,
mp_units::quantity<mp_units::one / east[m]>,
mp_units::quantity<mp_units::one / down[m]>>>;
using covariance = matrix<double, coordinates, coordinates>;
const auto beacon_range{
[](const position &point, const position &beacon) -> length {
return (point - beacon).magnitude();
}};
const auto beacon_range_jacobian{[](const position &point,
const position &beacon) -> range_jacobian {
const position displacement{point - beacon};
const length distance{displacement.magnitude()};
const auto [north_component, east_component, down_component]{displacement};
range_jacobian value;
value.at<0>((north_component / distance).numerical_value_in(mp_units::one) *
(mp_units::isq::length / north)[mp_units::one]);
value.at<1>((east_component / distance).numerical_value_in(mp_units::one) *
(mp_units::isq::length / east)[mp_units::one]);
value.at<2>((down_component / distance).numerical_value_in(mp_units::one) *
(mp_units::isq::length / down)[mp_units::one]);
return value;
}};
[[maybe_unused]] const auto sample{[] -> int {
// The beacons, in the order of their identifiers along the N pattern.
const position beacons[]{{north(0. * m), east(0. * m), down(-1. * m)},
{north(10. * m), east(0. * m), down(-3. * m)},
{north(0. * m), east(10. * m), down(-2. * m)},
{north(10. * m), east(10. * m), down(-1. * m)}};
const position receiver{north(3. * m), east(4. * m), down(-0.5 * m)};
const auto range_variance{0.1 * 0.1 * m2};
const double gate{3.}; // standard deviations
const int alignment_ranges{100};
kalman filter{
// The state X: the receiver's position, initially the beacons' centre.
state{coordinates{north(5. * m), east(5. * m), down(-1.75 * m)}},
// The output Z: a range [m].
output<range>,
// The estimate uncertainty P [m^2]:
estimate_uncertainty{[]() -> covariance {
covariance value;
value.at<0, 0>(25. * m2);
value.at<1, 1>(25. * m2);
value.at<2, 2>(25. * m2);
return value;
}()},
// The process uncertainty Q [m^2]:
process_uncertainty{[]() -> covariance {
covariance value;
value.at<0, 0>(1e-4 * m2);
value.at<1, 1>(1e-4 * m2);
value.at<2, 2>(1e-4 * m2);
return value;
}()},
// The output uncertainty R [m^2]:
output_uncertainty{range_variance},
// The output model H = ∂h/∂X, for the beacon of the range:
output_model{[](const coordinates &point,
const position &beacon) -> range_jacobian {
return beacon_range_jacobian(point, beacon);
}},
// The receiver is at rest: its prediction is its last estimate, so no
// transition function is declared.
// The observation h(X), the range to the beacon:
observation{[](const coordinates &point, const position &beacon)
-> range { return range{beacon_range(point, beacon)}; }},
// The filter update uses the position of the ranged beacon.
update_types<position>};
bool reflection_rejected{false};
const int ranges{400};
for (int index{0}; index < ranges; ++index) {
const position &beacon{beacons[index % 4]};
// Deterministic measurement noise, within one standard deviation, and one
// reflection three meters long.
length measured{beacon_range(receiver, beacon) +
(0.1 * std::sin(12.9898 * index) * m)};
const bool reflection{index == 300};
if (reflection) {
measured += 3. * m;
}
filter.predict();
// The consistency test of the range, computed outside of the filter.
const length innovation{measured - beacon_range(filter.x(), beacon)};
const range_jacobian jacobian{beacon_range_jacobian(filter.x(), beacon)};
// The one-element H P Hᵀ plus the variance R is the variance quantity S.
const auto innovation_variance{
(jacobian * filter.p() * transposed(jacobian)) + range_variance};
const bool consistent{innovation * innovation <
gate * gate * innovation_variance};
if (index < alignment_ranges || consistent) {
filter.update(beacon, measured);
} else if (reflection) {
reflection_rejected = true;
}
}
assert(reflection_rejected && "The multipath reflection is rejected.");
assert(beacon_range(filter.x(), receiver) < 0.1 * m &&
"The receiver position is found within ten centimeters.");
return 0;
}()};
