template<typename Callable >

const auto &... values )
constexpr

Assigns a callable characteristic from its copied initializers.

The closure type of a lambda expression with captures has a deleted copy assignment operator: such a callable is replaced in place instead. The replacement is constructed before the destruction of the assigned callable, and its non-throwing move construction never leaves the characteristic destroyed. Neither form allocates.

◆ deduce_element()

template<typename Type , std::size_t Position>
auto fcarouge::kalman_filter::internal::deduce_element ( )
nodiscardconsteval

Deduces the type of the element at the position of the type.

A backend names the element type of its matrices its own way, if at all: the type is deduced from the element access instead. The compile-time indexed access at<Position>() of a typed matrix, whose elements may each have their own type, otherwise the call operator (Position) of a matrix whose elements share a type. Void for a type without indexed element access, an arithmetic type for one.

The one matrix.

User-defined matrix with all its diagonal elements equal to ones, and zeroes everywhere else. This matrix is also known as the identity matrix for square matrices of non-quantity scalar types.

Warning
A user-defined specialization must be a constant expression, declared constexpr. The dynamic initialization of a templated variable is unordered: a filter constructed during the dynamic initialization of another object of static storage duration would copy its zero-initialized storage. Specialize the ones factory instead for a value that is not a constant expression.
