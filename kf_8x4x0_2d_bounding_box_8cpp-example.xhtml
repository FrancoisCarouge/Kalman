Estimating the position of bounding boxes in image space.

Estimating the position of bounding boxes in image space.

Copyright
This example is transcribed from Nwojke's Deep SORT filter.
See also
https://github.com/nwojke/deep_sort

In this example, we would like to estimate the bounding box center position x, y, aspect ratio a, height h, and their respective velocities in image space. The filter models constant velocity dynamics. The prediction and observation models are linear.

The pedestrian walks left, back right, left again, then turns around. The uncertainties scale with the height of the box: a taller, closer box moves more pixels for the same motion. Deep SORT gates the association of a detection to a track by the squared Mahalanobis distance of the innovation, against the 95% quantile of the chi-square distribution of four degrees of freedom, 9.4877. Its mean, four for a consistent filter, is less than one: the noise model is conservative. Only the jump of the box height at the tenth frame falls beyond the gate.

Note
For information, the original sample appears to saturate the velocity precision early on.

&initial_box]() -> matrix<float, 8, 8> {
matrix<float, 8, 8> value{kf::make_zero<matrix<float, 8, 8>>()};
value(0, 0) = std::powf(2.F * position_weight * initial_box(3), 2);
value(1, 1) = std::powf(2.F * position_weight * initial_box(3), 2);
value(2, 2) = std::powf(1e-2F, 2);
value(3, 3) = std::powf(2.F * position_weight * initial_box(3), 2);

const float weight_velocity{1.F / 160.F};
matrix<float, 8, 8> value{kf::make_zero<matrix<float, 8, 8>>()};
value(0, 0) = std::powf(weight_position * x(3), 2);
value(1, 1) = std::powf(weight_position * x(3), 2);
value(2, 2) = std::powf(1e-2F, 2);
value(3, 3) = std::powf(weight_position * x(3), 2);
value(4, 4) = std::powf(weight_velocity * x(3), 2);
value(5, 5) = std::powf(weight_velocity * x(3), 2);
value(6, 6) = std::powf(1e-5F, 2);

value(1, 1) = std::powf(weight_position * x(3), 2);
value(2, 2) = std::powf(1e-1F, 2);
value(3, 3) = std::powf(weight_position * x(3), 2);
return value;

{0.F, 0.F, 1.F, 0.F, 0.F, 0.F, delta_time, 0.F},
{0.F, 0.F, 0.F, 1.F, 0.F, 0.F, 0.F, delta_time},
