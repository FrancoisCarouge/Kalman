The Air Data

The true airspeed is the magnitude of the air velocity, the indicated airspeed its reading by the airspeed sensor. Their ratio is the scale factor of the sensor. The sideslip is the ratio of the right air velocity to the forward one. Both ratios are dimensionless quantity kinds of their own: a scale factor is never added to, nor substituted for, a sideslip.

The output model H = ∂h/∂X: the derivative of the observation by the state, evaluated at the estimate.

The derivative of the airspeed by the scale is the true airspeed. The derivatives of the airspeed by the wind are the opposite of the scale times the unit vector of the air velocity. The derivatives of the sideslip by the wind combine the body velocities, as the rotation into the body frame does. The ratios of the speeds are restated as the derivatives.

381 output_uncertainty{[&]() -> reading_covariance {
382 reading_covariance value;
383 value.at<0, 0>(airspeed_deviation * airspeed_deviation);
384 value.at<1, 1>(sideslip_deviation * sideslip_deviation);
385 return value;
386 }()},
387 // The output model H = ∂h/∂X, of the ground velocity and the heading:
388 output_model{observation_jacobian},
389 // The wind and the scale factor are constant: their prediction is their
390 // last estimate, so no transition function is declared.
391 // The observation h(X) of the airspeed and the sideslip:
392 observation{observe},
393 // The filter update uses the ground velocity and the heading.
394 update_types<velocity, heading>};
395
396 // The consistency test of the observations, computed outside of the filter:
397 // each innovation within its gate.
398 const auto consistent{[&filter, gate](const velocity &ground,
399 const heading &nose,
400 const reading &measured) -> bool {
401 const reading innovation{measured - observe(filter.x(), ground, nose)};
402 const reading_jacobian jacobian{
403 observation_jacobian(filter.x(), ground, nose)};
404 const reading_covariance innovation_uncertainty{
405 (jacobian * filter.p() * transposed(jacobian)) + filter.r()};
406 return innovation.at<0>() * innovation.at<0>() <
407 gate * gate * innovation_uncertainty.at<0, 0>() &&
408 innovation.at<1>() * innovation.at<1>() <
409 gate * gate * innovation_uncertainty.at<1, 1>();
410 }};
411
412 int spikes_fused{0};
413 int consistent_rejected{0};
414 heading nose{0. * rad};
415 const int steps{3000};
416 for (int step{0}; step < steps; ++step) {
417 // The heading is that of the air velocity: the flight is coordinated.
418 const speed air_speed{true_speed};
419 const velocity ground{
420 north_velocity(air_speed * mp_units::si::cos(nose)) + wind_north,
421 east_velocity(air_speed * mp_units::si::sin(nose)) + wind_east,
422 down_velocity(0. * m / s)};
423 // Every tenth step, an airspeed corrupted by a spike.
424 const bool spike{step % 10 == 5};
425 const reading measured{
426 indicated_airspeed(scale * true_speed) +
427 (airspeed_deviation * noise()) +
428 (spike ? spike_height : 0. * indicated_airspeed[m / s]),
429 sideslip_deviation * noise()};
430
431 filter.predict();
432
433 if (consistent(ground, nose, measured)) {
434 filter.update(ground, nose, measured);
435
436 // Keep the scale factor within its bounds.
437 air_data bounded{filter.x()};
438 bounded.at<2>(std::clamp(bounded.at<2>(),
439 0.5 * airspeed_scale[mp_units::one],
440 1.5 * airspeed_scale[mp_units::one]));
441 filter.x(bounded);
442
443 spikes_fused += static_cast<int>(spike);
444 } else {
445 consistent_rejected += static_cast<int>(!spike);
446 }
447
448 nose += turn_rate * time_step;
449 }
450
451 // The wind and the scale factor are found, the spikes rejected, whatever the
452 // seed of the noise. At five standard deviations, a consistent update is
453 // rejected about once in three hundred runs.
454 assert(abs(filter.x().at<0>() - wind_north) < 0.25 * m / s &&
455 abs(filter.x().at<1>() - wind_east) < 0.25 * m / s &&
456 "The wind is found within a quarter of a meter per second.");
457 assert(abs(filter.x().at<2>() - scale) < 0.01 * mp_units::one &&
458 "The airspeed scale factor is found within a percent.");
459 assert(spikes_fused == 0 && "The spikes are rejected.");
460 assert(consistent_rejected <= 2 &&
461 "Nearly every consistent update is fused.");
462
463 return 0;
464}()};

The horizontal air velocity rotated by the heading into the body frame.

The rotation pairs the components of different axes: the forward velocity sums the north and the east velocities, weighted by the cosine and the sine of the heading. Each component is restated as a speed, their common quantity, whose rotated sums are restated as the body velocities.
